# سامانه فول‌استک آوین — نسخه ویژه GitHub + Cloudflare Pages

این پروژه به‌طور اختصاصی برای معماری **GitHub → Cloudflare Pages** طراحی و بهینه‌سازی شده است تا بدون هیچ خطای سازگاری (مانند محدودیت‌های فایل‌سیستم لینوکس یا پکیج‌های بومی Node در لبه کلادفلر) مستقیماً از گیت‌هاب روی کلادفلر دیپلوی شود.

---

## چرا این معماری برای GitHub + Cloudflare طراحی شده است؟

در روش گیت‌هاب-کلادفلر، کدها روی شبکه لبه (**Cloudflare Edge / Workers**) اجرا می‌شوند و فایل دیتابیس محلی (`file:./dev.db`) روی سرور کلادفلر ماندگار نیست. به همین دلیل در این نسخه:
۱. **بک‌اند مبتنی بر Cloudflare Pages Functions (`/functions/api/*`)**: تمام APIها در پوشه `functions/` قرار دارند که کلادفلر هنگام اتصال به گیت‌هاب، آن‌ها را به‌صورت خودکار به Serverless Worker تبدیل می‌کند.
۲. **پشتیبانی دوگانه ذخیره‌سازی (Dual-Storage)**:
   - **روش اول (بدون نیاز به ساخت دیتابیس — Git-CMS)**: پنل مدیریت می‌تواند تغییرات شما را مستقیماً از طریق GitHub API داخل فایل `public/data/site-data.json` مخزن گیت‌هاب کامیت کند تا کلادفلر خودکار سایت را آپدیت کند.
   - **روش دوم (دیتابیس ابری رایگان Cloudflare D1)**: با اتصال یک دیتابیس D1 با نام `DB` در پنل کلادفلر، تمام جداول و ۹ محصول اولیه آوین در اولین بازدید به‌صورت **کاملاً خودکار** ساخته می‌شوند و تغییرات در لحظه اعمال می‌گردند.
۳. **احراز هویت بومی با Web Crypto API**: بدون وابستگی به پکیج‌های سنگین Node.js که در محیط Edge کلادفلر خطا می‌دهند.

## راهنمای گام‌به‌گام استقرار در GitHub و Cloudflare Pages

### گام ۱: قرار دادن کدها در GitHub
۱. فایل‌های این پروژه را در یک مخزن (Repository) جدید در اکانت GitHub خود آپلود یا Push کنید:
```bash
git init
git add .
git commit -m "Initial commit: Avin Cloudflare Fullstack"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
git push -u origin main
```

### گام ۲: اتصال GitHub به Cloudflare Pages
۱. وارد داشبورد **Cloudflare** شوید و از منوی سمت چپ به بخش **Workers & Pages** بروید.
۲. روی دکمه **Create** کلیک کنید، تب **Pages** را انتخاب کرده و گزینه **Connect to Git** را بزنید.
۳. مخزن گیت‌هاب خود را انتخاب کنید و در بخش تنظیمات Build مقادیر زیر را قرار دهید:
   - **Framework preset**: `Vite` (یا `None`)
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
۴. روی **Save and Deploy** کلیک کنید. ظرف کمتر از ۱ دقیقه سایت شما بالا می‌آید!

---

## گام ۳: انتخاب روش ذخیره‌سازی در پنل مدیریت (`/admin`)

پس از باز کردن آدرس سایت، به مسیر `/admin` بروید و با اطلاعات پیش‌فرض زیر وارد شوید:
- **نام کاربری:** `admin`
- **رمز عبور:** `admin123`

سپس در منوی کناری پنل مدیریت به بخش **«اتصال گیت‌هاب و کلادفلر»** بروید و یکی از دو روش زیر را انتخاب کنید:

### حالت الف) انتشار مستقیم در GitHub (بدون نیاز به دیتابیس D1)
۱. در گیت‌هاب به مسیر **Settings → Developer settings → Personal access tokens → Tokens (classic)** بروید و یک توکن با دسترسی `repo` بسازید.
۲. در پنل ادمین سایت، نام مخزن (`username/repo`) و توکن را وارد کنید.
۳. هر زمان محصولی اضافه کردید یا متنی را تغییر دادید، با زدن دکمه **«انتشار مستقیم تغییرات در GitHub»**، تغییرات مستقیماً در گیت‌هاب ذخیره شده و کلادفلر سایت را به‌روز می‌کند.

### حالت ب) استفاده از دیتابیس ابری Cloudflare D1 (اعمال آنی در لحظه)
۱. در داشبورد کلادفلر به منوی **Workers & Pages → D1 SQL Database** بروید و یک دیتابیس به نام `avin-db` بسازید.
۲. وارد پروژه Pages خود شوید و به تب **Settings → Functions → D1 database bindings** بروید.
۳. یک Binding جدید با نام متغیر **`DB`** اضافه کنید و آن را به `avin-db` متصل نمایید.
۴. یک بار پروژه را Redeploy کنید؛ جداول و محصولات اولیه به‌صورت خودکار ساخته می‌شوند!
