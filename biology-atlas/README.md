# اطلس مشروح گیرنده‌های حسی — فصل ۲: حواس

بازسازی برداری، برچسب‌گذاری ریزبینانه و تکمیل علمیِ **هر پنج شکل** دفتر درسی
(صفحات ۱۹ تا ۲۳) به‌همراه بانک پرسش چالشی و پاسخنامهٔ تشریحی.

## خروجی‌ها

| فایل | توضیح |
| --- | --- |
| `atlas.pdf` | نسخهٔ چاپی A4 (۲۷ صفحه، برداری، فارسی راست‌به‌چپ) |
| `atlas.html` | نسخهٔ خودبسنده تک‌فایلی (SVG‌های درون‌خط، بدون منبع بیرونی) |

هر دو خروجی از یک منبع تولید می‌شوند: `build/parts/*.html` (متن) + `build/figs/*.svg` (لوحه‌ها).

## ساختار محتوا

1. **جلد و راهنما** — چگونه بخوانیم، نقشهٔ مفهومی «از محرک تا ادراک»، سه زبان رمزگذاری.
2. **لوحهٔ ۱** — دستهٔ مویی یاختهٔ مویی حلزون (نگارهٔ SEM صفحهٔ ۱۹) + بزرگ‌نمایی پیوند نوکی.
3. **لوحهٔ ۲** — مولد پیام عصبی در گیرندهٔ مکانیکی (شکل ۱، ص ۲۰) + دو نمودار رمزگذاری.
4. **لوحهٔ ۳** — گیرنده‌های پوست (شکل ۲، ص ۲۱) + دقت مکانی، سرعت فیبر و پنجرهٔ بسامدی.
5. **لوحهٔ ۴** — دوک عضلانی و اندام وتری (شکل ۳، ص ۲۲) + دو قوس بازخوردی نخاعی.
6. **لوحهٔ ۵** — ساختار کرهٔ چشم (شکل ۴، ص ۲۳) + مسیر زلالیه، اعداد کلیدی، همگرایی شبکیه.
7. **جداول تطبیقی** — گیرنده‌ها، پتانسیل مولد در برابر پیام عصبی، دوک در برابر اندام وتری، اعداد چشم.
8. **۲۷ پرسش** — ۱۲ چهارگزینه‌ای، ۶ شکل‌خوانی، ۵ استدلالی، ۴ ترکیبی/المپیادی.
9. **پاسخنامهٔ تشریحی**، **واژه‌نامه** و **منابع**.

هر لوحه چهار لایه دارد: جدول کلید (نام + معادل لاتین + اطلاعات ریز)،
«لایهٔ پیشرفته» (داده‌های بیرون از کتاب)، «محتوای پنهان شکل» و «دام‌های آزمونی».

## بازسازی خروجی‌ها

```bash
cd build
./make_pdf.sh      # همهٔ لوحه‌ها را می‌سازد، HTML را می‌چیند و PDF چاپی می‌سازد
```

اجزای خط تولید:

- `svgkit.py` — ابزار کوچک ساخت SVG (متن راست‌به‌چپ، برچسب شماره‌دار، کادر، فلش).
- `fig1_haircell.py` … `fig5_eye.py` — هر لوحه یک اسکریپت؛ خروجی در `figs/figN.svg`.
- `style.css` — طرح چاپی A4، RTL، کادرهای رنگی و جدول‌ها.
- `build.py` — چیدن `parts/*.html` و جای‌گذاری SVG‌ها در `../atlas.html`.
- `make_pdf.sh` — چاپ با Chromium بی‌سر: `atlas.html` ← `atlas.pdf`.
- `preview.sh` / `qa_part.sh` — ابزار بازبینی تصویری هر لوحه یا هر بخش به‌صورت جداگانه.

## یادداشت روش‌شناسی

- تصاویر «بازسازی» هستند، نه عکس اصلی: هندسه برای خوانایی آموزشی ساده شده و
  مقیاس واقعی هر ساختار در جدول‌ها آمده است.
- همهٔ برچسب‌ها با شماره روی تصویر نشسته‌اند و کلید کامل (فارسی + لاتین + عدد) زیر هر لوحه است.
- داده‌های «لایهٔ پیشرفته» از Guyton & Hall، Kandel، Purves، Alberts، Junqueira،
  Boron & Boulpaep و منابع تخصصی تبدیل مکانیکی گرفته شده‌اند.
- ریشهٔ SVG با `direction="ltr"` تولید می‌شود تا معنای `text-anchor` مستقل از
  جهت راست‌به‌چپ صفحه بماند.
